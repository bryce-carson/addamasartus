* NexusMods Personal API key
You can't have mine, but you can put yours in your =.Rprofile= file in your
=${XDG_CONFIG_DIR}=.

This key is used to query Nexus Mods for information related to mod updates,
compatibility, dependencies, etc. The new {nexusmods} R package (which I wrote
for use by this package) wraps version one of the NexusMods API. That package is
required for the mentioned features to work. Support for the features utilizing
web scraping instead will not be implemented, out of respect for the Nexus team
and the modders who benefit from the advertisements the Nexus hosts on their
virtual real estate.
